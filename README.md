# עין התקשורת - כלי מעקב תקשורת אישי

כלי שסורק אוטומטית אתרי חדשות ישראליים וערוצי טלגרם ציבוריים, מזהה אזכורים של
המטרות שהגדרת (אנשים, נושאים, מילות מפתח), שולח התראות לטלגרם ומייצר סיכום
בעברית פעמיים ביום. הכל רץ בחינם על GitHub Actions, והתוצאות מוצגות בדשבורד
גלוי (GitHub Pages) ובתיקיית `digests/`.

הרעיון והארכיטקטורה מבוססים על הכלי שנחשף בכתבת "הארץ" (ספטמבר 2026) אודות
כלי המעקב שיונתן אוריך בנה - פרטים ולינקים במדריך המצורף בדרייב.

## מה הכלי עושה

1. **סריקה שעתית** של מקורות חדשותיים בשלוש שיטות:
   - פידי RSS ישירים (ynet, וואלה, גלובס, TheMarker, אייס, מעריב, i24).
   - **סריקת דף-בית עם דירוג בולטות** (הארץ, N12) - הגישה של הכלי המקורי:
     המיקום של כותרת בדף הבית קובע את משקלה (סיפור ראשי x10, 2-5 בראש x5,
     6-10 x3, 11-20 x1). ככה יודעים לא רק *שהוזכרת* אלא *כמה בולט*.
   - חיפוש Google News בעברית לכל מטרה (מכסה גם אתרים שחוסמים סריקה ישירה:
     ישראל היום, כלכליסט, כאן, ערוץ 14, רשת 13, מקור ראשון).
   - עמודי ה-web הציבוריים של ערוצי טלגרם.
2. **זיהוי אזכורים** לפי מילות מפתח מותאמות-עברית (מזהה גם צורות עם אותיות
   קידומת: לנתניהו, שאיראן).
3. **דירוג חשיבות**: ציון = משקל המטרה x משקל המקור + בונוס בולטות
   (אזכור בסיפור המוביל של אתר מקבל +6). כל מקור מסומן גם בנטייה משוערת
   (ימין/מרכז/שמאל) לניתוח איזון בדשבורד.
4. **התראות מיידיות לטלגרם** על פריטים מעל סף החשיבות (אופציונלי).
5. **סיכום בוקר וערב** בעברית בתיקיית `digests/` - וגם נשלח לטלגרם.
   אם מוסיפים מפתח Anthropic, קלוד מוסיף ניתוח קצר לכל מטרה (אופציונלי).
6. **דשבורד**: עמוד סטטי ב-GitHub Pages עם האזכורים האחרונים, פילוג לפי
   מטרה/מקור/נטייה, ומדור "סיפורים מובילים".

## הפעלת התראות הטלגרם - הפעולה האחת שנותרה

הקוד מוכן ומחכה; חסר רק חיבור הבוט שלך:

1. בטלגרם: פתח שיחה עם **@BotFather**, שלח `/newbot`, וקבל טוקן.
2. שלח הודעה כלשהי לבוט החדש, ואז פתח שיחה עם **@userinfobot** כדי לקבל
   את מספר ה-chat id שלך.
3. בריפו: **Settings -> Secrets and variables -> Actions** והוסף שני סודות:
   `TELEGRAM_BOT_TOKEN` (הטוקן) ו-`TELEGRAM_CHAT_ID` (המספר).
4. בדיקה: **Actions -> telegram-test -> Run workflow** - אם הכול תקין תקבל
   הודעת "הבוט מחובר ועובד" בטלגרם. מרגע זה ההתראות והסיכומים זורמים.

## הגדרה ב-5 דקות (מאפס)

1. צור ריפו חדש ב-GitHub והעלה אליו את כל הקבצים (או השתמש בזה כתבנית).
2. ערוך את `config/targets.yaml` - שם מגדירים אחרי מה לעקוב (יש בלוק מוכן
   למעקב בסגנון הכלי המקורי, מסומן בהערות).
3. ערוך את `config/sources.yaml` - הפעל/כבה מקורות וקבע משקלים.
4. הגדר את סודות הטלגרם כמתואר למעלה (אופציונלי).
   `ANTHROPIC_API_KEY` לניתוח AI בסיכומים - אופציונלי נוסף; בלעדיו הסיכום
   הוא רשימת הכותרות בלבד, בחינם לגמרי.
5. Settings -> Pages -> Deploy from branch -> main -> /docs - והדשבורד באוויר
   בכתובת `https://<השם-שלך>.github.io/<שם-הריפו>/`.

## הרצה מקומית

```bash
pip install -r requirements.txt
python -m pipeline.run            # סריקה מלאה
python -m pipeline.digest         # בניית סיכום עכשיו (+ שליחה לטלגרם אם מוגדר)
python scripts/test_telegram.py   # בדיקת חיבור הבוט
```

## כמה זה עולה

- ריפו ציבורי + GitHub Actions: **חינם** (סריקה שעתית צורכת כ-2 דקות מחשוב
  ליום, רחוק מהמכסה החינמית גם בריפו פרטי).
- ניתוח AI של קלוד בסיכומים: אופציונלי, סדר גודל של שקלים בודדים בחודש.
- מעקב בזמן אמת (כל 90 שניות כמו בארץ המקור) דורש שרת קטן משלך - ב-GitHub
  Actions המינימום הסביר הוא שעתי. פרטים במדריך.
