# עין התקשורת - כלי מעקב תקשורת אישי

כלי שסורק אוטומטית אתרי חדשות ישראליים וערוצי טלגרם ציבוריים, מזהה אזכורים של
המטרות שהגדרת (אנשים, נושאים, מילות מפתח), שולח התראות לטלגרם ומייצר סיכום
בעברית פעמיים ביום. הכל רץ בחינם על GitHub Actions, והתוצאות מוצגות בדשבורד
גלוי (GitHub Pages) ובתיקיית `digests/`.

הרעיון והארכיטקטורה מבוססים על הכלי שנחשף בכתבת "הארץ" (24.9.2026) אודות
כלי המעקב שיונתן אוריך בנה - פרטים ולינקים במדריך המצורף.

## מה הכלי עושה

1. **סריקה שעתית** של מקורות חדשותיים: פידי RSS ישירים, חיפוש Google News
   בעברית לכל מטרה (מכסה גם אתרים שחוסמים סריקה ישירה), ועמודי ה-web הציבוריים
   של ערוצי טלגרם.
2. **זיהוי אזכורים** לפי מילות מפתח מותאמות-עברית (מזהה גם צורות עם אותיות
   קידומת: לנתניהו, שאיראן).
3. **דירוג חשיבות**: ציון = משקל המטרה x משקל המקור. כל מקור וכל מטרה
   מקבלים משקל 1-5 בקבצי הקונפיגורציה.
4. **התראות מיידיות לטלגרם** על פריטים מעל סף החשיבות (אופציונלי).
5. **סיכום בוקר וערב** בעברית בתיקיית `digests/`. אם מוסיפים מפתח
   Anthropic, קלוד מוסיף ניתוח קצר לכל מטרה (אופציונלי, עולה אגורות).
6. **דשבורד**: עמוד סטטי ב-GitHub Pages עם כל האזכורים האחרונים.

## הגדרה ב-5 דקות

1. צור ריפו חדש ב-GitHub והעלה אליו את כל הקבצים (או השתמש בזה כתבנית).
2. ערוך את `config/targets.yaml` - שם מגדירים אחרי מה לעקוב.
3. ערוך את `config/sources.yaml` - הפעל/כבה מקורות וקבע משקלים.
4. ב-GitHub: Settings -> Secrets and variables -> Actions:
   - `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` להתראות (אופציונלי).
     יוצרים בוט חינם אצל @BotFather בטלגרם, ומקבלים את ה-chat id דרך
     @userinfobot אחרי ששולחים הודעה לבוט.
   - `ANTHROPIC_API_KEY` לניתוח AI בסיכומים (אופציונלי; בלעדיו הסיכום
     הוא רשימת הכותרות בלבד, בחינם לגמרי).
5. Settings -> Pages -> Deploy from branch -> main -> /docs - והדשבורד באוויר
   בכתובת `https://<השם-שלך>.github.io/<שם-הריפו>/`.

## הרצה מקומית

```bash
pip install -r requirements.txt
python -m pipeline.run            # סריקה מלאה
python -m pipeline.digest         # בניית סיכום עכשיו
```

## כמה זה עולה

- ריפו ציבורי + GitHub Actions: **חינם** (סריקה שעתית צורכת כ-2 דקות מחשוב
  ליום, רחוק מהמכסה החינמית גם בריפו פרטי).
- ניתוח AI של קלוד בסיכומים: אופציונלי, סדר גודל של שקלים בודדים בחודש.
- מעקב בזמן אמת (כל 90 שניות כמו בארץ המקור) דורש שרת קטן משלך - ב-GitHub
  Actions המינימום הסביר הוא שעתי. פרטים במדריך.
